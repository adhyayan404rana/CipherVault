Security properties
Confidentiality: AES-256-GCM encrypts file contents. Integrity: GCM rejects modified packages; SHA-256 compares recovered bytes. Authenticity: RSA-PSS verifies signed content relative to a public key you trust.

Hash resistance experiments
Preimage: find an input for a given hash. Second preimage: find a different input with the same hash as a fixed input. Collision: find any two different inputs with the same hash.
Uses generated demonstration inputs, not your uploaded files. Full SHA-256 searches are capped at 5,000 candidates; shortened 8/12/16-bit prefixes make search behaviour visible. This illustrates the concepts and does not prove or break SHA-256 resistance.
